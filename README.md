# The Money Stroll

A small Three.js animation: a bald, bearded man in a navy shirt and jeans strolls and whistles around a plaza while Canadian-style bills, loonies and toonies shake off him like leaves. A running tally climbs about 500 a minute.

Tap him to shake loose an extra burst of money. Drag (or touch and drag) on the street to steer him. Phones get a lighter graphics mode automatically.

Open `index.html` in a browser, or view it on GitHub Pages.
